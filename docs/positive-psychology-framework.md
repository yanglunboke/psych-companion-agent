# 中学积极心理陪伴智能体 · 积极心理学框架说明

> 本文档按「核心模型 → 测量工具 → 干预方法」三段梳理，**每一条都标注了代码落点**，
> 便于核对与答辩。所有描述均为系统**已实现**的行为，未实现的部分在文末单列说明。

---

## 一、核心模型

系统理论底座是**积极心理学**，但不是"只说好话"式的鸡汤安慰，而是三条技术路线并行：

```
                 ┌─────────────────────────────────────────┐
   评估层         │  情绪识别 Worker（情绪/诱因/认知偏差）    │  ← 过程性测量
                 │  风险打分 Worker（0-1 连续风险分）        │
                 └────────────────┬────────────────────────┘
                                  ↓
   匹配层         │  需求澄清 Worker（需求 + 干预档位 4 档）   │
                 └────────────────┬────────────────────────┘
                                  ↓
   干预层         │  积极引导 Worker（策略卡驱动 + 理论引用）   │
                 │  资源建议 Worker（8 类结构化练习）          │
                 └────────────────┬────────────────────────┘
                                  ↓
   安全层         │  风险分级 → 固定上报流程（老师/家长端）    │
                 └─────────────────────────────────────────┘
```

### 1.1 优势聚焦（Strengths-Based）—— 对应 PERMA 与 VIA

积极心理学的核心转向是"从修补缺陷到发现优势"。系统把它做成了**可累积的侧写字段**：

| 机制 | 实现 | 代码落点 |
|---|---|---|
| 自述优势提取 | 正则捕捉"我擅长X""我的优点是X""我拿手X" | `app/memory/profile.py:extract_strengths` |
| VIA 品格优势识别 | 8 类关键词映射（韧性/创造力/同理心/勇敢/感恩/好奇心/自律/善良） | `app/memory/profile.py:extract_via_strengths` |
| 优势 Top3 排序 | 按证据次数降序，只保留前 3，避免优势清单膨胀 | `profile.py:update_profile` 第 5 步 |
| 优势回灌干预 | 策略卡固定含「优势强化」步骤，强制在对话中点出学生已做到的部分 | `app/rag/query.py:infer_steps` |

**设计要点**：优势不是模型临时夸一句，而是**跨轮次累积**的结构化结论，回填进每一轮 prompt 的侧写摘要里。

### 1.2 认知模型 —— 对应 REBT（理性情绪行为疗法）

情绪不是直接回应对象，而是通过**认知歪曲**这一中介变量处理的：

| 环节 | 实现 |
|---|---|
| 认知偏差识别 | 5 类歪曲：以偏概全 / 灾难化 / 非黑即白 / 过度自责 / 读心术 |
| 偏差 → 干预步骤映射 | `DISTORTION_STEPS`：以偏概全→认知解离+优势强化；灾难化→认知解离；非黑即白→认知解离；过度自责→优势强化；读心术→事实澄清 |
| 固定干预步骤链 | 共情接纳 → 认知解离 → 优势强化 → 只问一个问题 |

「认知解离」是 REBT 里 D（Dispute，辩驳）的工程化落地：策略卡要求把"一次考试结果"与"我这个人没用"**拆开**。

### 1.3 归因风格 —— 对应 Weiner 归因理论 / 塞利格曼解释风格

系统同时测量归因的**正负两侧**并做对比推断：

```
积极归因证据数 ≥ 3 且 > 稳定偏差数  →  积极归因
稳定偏差数 ≥ 3 且 ≥ 积极归因证据数  →  消极归因
否则                                →  尚未明确
```

代码落点：`app/memory/profile.py:infer_attribution_style`。

积极认知资源（成长型思维 / 积极归因 / 自我接纳）用**与认知偏差完全相同的 3 次交叉验证门槛**采集，保证两侧证据量可比（`profile.py:extract_positive_cognitions`）。

### 1.4 情绪轨迹 —— 过程性评估

不用单点情绪做决策，而是维护平滑后的强度序列：

- **EMA 平滑**：`新值 = 0.7 × 旧值 + 0.3 × 本轮`（`smooth_intensity`，alpha=0.3）—— 防止一句气话改写主导情绪
- **趋势检测**：相邻两次 EMA 比较，差值 > 0.15 判为「上升/下降」，否则「平稳」（`detect_emotion_trend`）
- **诱因记忆**：只记录"有实质情绪"的轮次，避免平淡发言冲掉上次诱因（`update_profile` 第 4 步）

情绪类型与诱因域还会经 `infer_scene` 映射到 **19 个场景标签**（exam_failure / peer_conflict / family_conflict / self_doubt / loneliness / bullying / appearance / procrastination …），作为检索入口。

### 1.5 知识供给：双通道 RAG

| 通道 | 内容 | 作用 |
|---|---|---|
| 策略通道 | 18 张场景回应卡 + 12 张禁止说法卡 | 约束"**怎么回应**"——流程与话术 |
| 理论通道 | 22 张积极心理学理论卡（《真实的幸福》第1章） | 提供"**依据什么**"——理论与研究证据 |

理论通道的三项专门设计（都是实测踩坑后定下来的）：

1. **独立限流**：走独立检索通道，`theory_top_k=2`，**不占用**策略卡的档位 K 名额。
   *踩坑*：最初与策略卡混在同一条流水线里竞争，不相关的理论卡挤占策略卡名额，
   实测「痛感如何改变决策」在"考试失利"和"焦虑睡不着"两个无关场景同时入选。
2. **独立阈值 + 语义主导重排**：理论卡全部 `scene="*"`，无场景匹配，重排分天然低于策略卡，
   故用独立阈值 `theory_rerank_min_score=0.35`（策略卡为 0.45），并以
   bge-m3 余弦相似度主导打分（`0.65 × 语义 + 0.35 × 关键词覆盖`）。
   *踩坑*：共用 0.45 阈值时，「我一点优点都没有」的 top1 得分 0.436，差 0.014 被误杀。
3. **检索锚点 + 内容指纹失效**：每张理论卡带 `keywords`（主题词 + **学生口语说法**），
   检索文本用「标题 + 关键词」而非长正文。
   *踩坑*：长正文在稠密向量空间里因词汇重叠而收敛——bge-m3 曾把 22 张理论卡判为
   同一张卡（top1/top2 分差仅 0.001，区间仅 0.365~0.514）。加锚点后分差拉开到 0.025~0.061。

   配套机制：`card_vectors` 表带 `content_hash` 列（检索文本的 SHA-256），
   卡片正文或关键词一改，指纹即失效、向量自动重编——否则库里存的是"旧文本的向量"，
   与当前语义完全错位。

## 二、测量工具

系统采用**对话过程内的连续评估**——每轮都测，而非依赖单次问卷。

### 2.1 情绪测量

结构化输出五个维度（`app/schemas.py:EmotionCore`）：

| 字段 | 取值 | 测量对象 |
|---|---|---|
| `emotion_type` | 平静/焦虑/沮丧/愤怒/委屈/自责/迷茫/恐惧/绝望/积极（10 类） | 情绪的**类型** |
| `intensity` | 1–5 整数 | 情绪的**强度** |
| `cause_domain` | 学业/人际/家庭/自我/未知（5 域） | 情绪的**诱因归属** |
| `cause_detail` | 自由文本 | 诱因的**具体内容** |
| `candidate_distortions` | 5 类认知歪曲（可空） | 认知层面的**中介变量** |
| `confidence` | 0–1 | 识别**把握程度** |

设计上有一条明确约束：**没有依据时 `candidate_distortions` 留空，不为凑数硬填**（见 `EMOTION_SYSTEM_PROMPT` 第 5 条）。

### 2.2 风险测量

- **量表**：0–1 连续风险分，由**独立的小模型**（temperature=0，更小更快）产出，与主回复模型分离
- **阈值**：0.72（文档给定，宁误报勿漏报）；侧写里另设 0.45 为中危档
- **词表**：`app/data/lexicon/high_risk_lexicon.json`，3 类 critical：
  - 明确的自伤或自杀（15 个词 + 2 条正则）
  - 明确的伤人（14 个词 + 2 条正则）
  - 未成年人受侵害（16 个词 + 2 条正则，含校内欺凌暴力与性侵害表述）
- **反向抑制**：4 条保护规则，识别"我不想死""我不会自杀""电影里有人跳楼"等**保护性表达与叙事语境**，避免误报

### 2.3 稳定性测量：证据计数法

单次出现的特征不进入侧写，必须**累计 3 次独立证据**：

```
evidence_count ≥ 3  →  进入 stable_distortions（稳定认知偏差）
positive_cognition_counts ≥ 3  →  进入 positive_cognitions（积极认知资源）
```

这是本系统区分"偶发情绪"与"稳定认知模式"的核心机制，也是防止侧写被单句话带偏的保险丝。

### 2.4 干预匹配测量

| 维度 | 取值 |
|---|---|
| `needs` | 被理解 / 被倾听 / 安全感 / 成就感 / 归属感 / 被公平对待 / 方法（7 类） |
| `intervention_fit` | 只想说说 / 情绪疏导 / 轻量引导 / 需要练习（4 档） |

档位判定口径明确规定：**学生明确说"只想说说"时绝不能给方法**。

### 2.5 优势测量

自述优势（正则）+ VIA 关键词识别 + 证据次数排序，三路合并成 Top3。

### 2.6 主观幸福感量表（已入库）

《真实的幸福》第1章引入的 **福代斯幸福测试**（PERMA 主观幸福感量表，10 点计分）作为参考工具入库，含常模数据（美国成人均值 6.92/10；54.13% 时间感觉幸福 / 20.44% 不幸福 / 25.43% 持平）。

### 2.7 输出质量自检（Reflection 复盘）

| 检查项 | 触发后果 |
|---|---|
| 一上来就讲道理 / 说教 | 记入本轮日志，**下一轮带一句提醒** |
| 学生说"只想说说"却给了方法 | 同上 |
| 结尾问了不止一个问题 | 同上（策略卡硬性规则） |
| 高危轮草稿含诊断词（抑郁症/双相/确诊/你应该去看医生…） | **草稿不发给学生**，同步闸门拦截 |

常规轮**异步**复盘（不拖慢响应），高危轮**同步**拦截。

## 三、干预方法

### 3.1 策略卡驱动的对话干预（主干）

策略卡 = 完整的一个干预单元，人工整卡编排，不按字数切分。每张包含：

```
id / scene / title / must（必须遵循的步骤）/ steps（策略步骤）/
applicable_fit（适用档位）/ applicable_distortions（适用认知偏差）/
forbidden_when（禁止启用场景）/ text（卡片全文，参与重排打分）
```

18 张场景卡覆盖：考试失利、考前焦虑、同伴冲突、家庭冲突、自我否定、孤独、校园欺凌、积极进展、考试进步后自我怀疑、选科压力、比赛挫败、外貌焦虑、好友转学、社团竞争落选、被老师误解、宿舍关系、父母管控、拖延。

**12 张禁止说法卡**与场景卡**同时检索**（同一次 RRF 召回），在积极引导阶段对生成结果做剔除——"能说什么"和"不能说什么"同时进上下文。

**执行硬约束**（`GUIDANCE_SYSTEM_PROMPT`）：

1. 先共情接纳——接住情绪，不评价、不比较、不急着给方法
2. 按策略卡步骤推进，不自创步骤
3. 点出韧性——让学生看见自己已经做到的部分
4. 结尾只问一个问题
5. 长度 3–5 句、不超过 200 字、像同龄朋友

### 3.2 结构化练习（8 类，16 张卡）

| 类别 | 卡 |
|---|---|
| 呼吸调节 | 4-7-8 呼吸、睡前 4-7-8 呼吸 |
| 感官着陆 | 5-4-3-2-1 感官着陆、身体扫描 |
| 书写表达 | 情绪书写、想法记录表 |
| 时间管理 | 担忧时段、25 分钟专注块 |
| 未来视角 | 未来的自己、价值排序、利弊清单 |
| 优势聚焦 | 优势记录 |
| 自我关怀 | 自我关怀三句话 |
| 睡眠与社交 | 睡前收尾三步、社交电量恢复 |

练习卡**只在 `intervention_fit = 需要练习` 时才可见**（靠 collection 隔离 + 档位门控），避免在学生只想被听的时候硬塞方法。

### 3.3 档位化干预匹配（四档 × 动态 K）

| 档位 | 含义 | 每轮卡片上限 K |
|---|---|---|
| 只想说说 | 只需被听见，禁止给方法 | 2 |
| 情绪疏导 | 接住情绪 + 轻度认知工作 | 3 |
| 轻量引导 | 加一个可操作的小练习 | 2 |
| 需要练习 | 完整的结构化练习 | 4 |

档位 K 与**断崖截断**（与第 2 名分差 > 0.15 即停）、**token 预算**（1200 字符）三重约束叠加，防止过度干预与上下文膨胀。

### 3.4 理论引用干预

22 张理论卡（塞利格曼《真实的幸福》第1章）供模型在合适时引用研究证据，prompt 明确约束：

> 仅在与当前回复真正相关时才引用（一句话带出即可），不要堆砌、不要为了显示专业而强行引用；不相关就完全不要提。

### 3.5 风险分层与固定上报

高危（≥0.72）时执行**固定上报流程**（不走自由发挥）：写入 outbox + 老师端 + 家长端通知渠道。三个 critical 类别同时是**保密例外**——学生说出后不能继续按普通倾诉处理。

### 3.6 迭代闭环

每轮回复经反思模块复盘，问题写入日志并**带到下一轮**作为提醒，形成"识别—干预—复盘—修正"的闭环。

## 四、架构上的两个特点

### 4.1 双模型分工

主回复模型（temperature=0.3，做共情表达）与风险打分模型（更小、更快、temperature=0，做判定）**分离**。判定与表达解耦，避免"表达生成"的不确定性污染风险判断。

### 4.2 可降级性

模型不可用时自动降级到本地规则引擎并熔断；向量库不可用时降级到内存索引；词表命中与模型判断在安全门里**双路并行**，任一路触发即拦截。系统在完全离线环境下仍能跑通全链路。

## 五、尚未实现的部分（诚实边界）

以下是当前**没有**做、但正式研究需要补上的：

1. **标准化量表的正式施测**：现有测量是"对话过程内的连续评估"，不是 PHQ-9 / GAD-7 这类标准化问卷的前测—后测设计，因此**尚无信效度检验数据**。
2. **对照组与效果量**：无实验设计，无法给出干预前后的显著性与效应量。
3. **理论卡的实证检验**：22 张理论卡目前只做语义检索命中验证，未做"引用理论是否提升回复质量"的人工评分。
4. **理论卡的主题化**：当前理论卡靠 `keywords` 锚点 + 语义相似度路由；若要更可控，可给理论卡加**结构化主题标签**（如 longevity / character_strengths / subjective_wellbeing）做二级过滤。
5. **测量工具的效度验证**：认知偏差的 5 类识别目前依赖 LLM 判断，尚无人工标注的标注者间一致性（Krippendorff's α）数据。
6. **理论卡引用的人工评估**：当前只验证了"检索命中是否正确"，尚未评估"模型引用理论后，回复质量是否真的提升"。
